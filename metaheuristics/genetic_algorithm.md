# Genetic Algorithm for CVRP

## Overview
This implementation uses a Genetic Algorithm (GA) to solve the Capacitated Vehicle Routing Problem (CVRP). A Genetic Algorithm is an evolutionary heuristic that mimics the process of natural selection. It maintains a population of candidate solutions and iteratively evolves them through selection, crossover, and mutation operators to find near-optimal solutions.

## Representation
### Genome (Giant Tour)
The problem solution is encoded as a **single permutation of all customer nodes**, often called a "Giant Tour". The depot is excluded from this sequence.

### Decoding (Split Procedure)
To evaluate the fitness (cost) of a genome, we must convert the giant tour into valid vehicle routes. This implementation uses a simple greedy "Split" procedure:
1. Iterate through the sequence of customers.
2. Add customers to the current route until the vehicle capacity is exceeded.
3. Once capacity is reached, start a new route.

```python
def _decode(self, node_sequence: List[Node]) -> Solution:
    routes = []
    current_route_nodes = []
    current_load = 0
    # ...
    for customer in node_sequence:
        if current_load + customer.demand > self.model.capacity:
            # Close current route and start a new one
            routes.append(self._create_route(route_counter, current_route_nodes))
            # ...
            current_route_nodes = []
            current_load = 0
        
        current_route_nodes.append(customer)
        current_load += customer.demand
    # ...
```

## Algorithm Components

### 1. Initialization
The initial population is generated by creating random permutations of customers.

```python
def _initial_population(self) -> List[Solution]:
    pop = []
    for _ in range(self.population_size):
        perm = self.customers[:]
        random.shuffle(perm)
        pop.append(self._decode(perm))
    return pop
```

### 2. Selection (Tournament)
Tournament selection is used to choose parents for the next generation. A subset of individuals is chosen at random, and the best one among them is selected. This pressure drives the population towards better solutions.

```python
def _tournament_selection(self, population: List[Solution]) -> Solution:
    competitors = random.sample(population, self.tournament_size)
    return min(competitors, key=lambda s: s.cost)
```

### 3. Crossover (Order Crossover - OX1)
The **Order Crossover (OX)** operator is used to combine two parents. It preserves a subsequence from the first parent and fills the remaining spots with genes from the second parent in the order they appear, ensuring valid permutations.

```python
def _crossover(self, parent1: Solution, parent2: Solution) -> List[Node]:
    # ...
    start, end = sorted(random.sample(range(size), 2))
    
    child = [None] * size
    child[start:end] = genome1[start:end]
    
    # Fill remaining from parent2
    p2_idx = 0
    for i in range(size):
        if child[i] is None:
            while genome2[p2_idx] in child:
                p2_idx += 1
            child[i] = genome2[p2_idx]
            
    return child
```

### 4. Mutation (Swap)
To maintain diversity and avoid local optima, a **Swap Mutation** is applied with a low probability (`mutation_rate`). It simply swaps the positions of two random nodes in the genome.

```python
def _mutate(self, genome: List[Node]):
    if random.random() < self.mutation_rate:
        i, j = random.sample(range(len(genome)), 2)
        genome[i], genome[j] = genome[j], genome[i]
```

### 5. Elitism
The best solution from the current generation is always preserved (copied directly) to the next generation. This ensures that the algorithm never loses the best solution found so far.

## Parameters
The behavior of the GA is controlled by the following parameters:
- **`population_size`** (Default: 100): Number of individuals in each generation.
- **`generations`** (Default: 500): Number of iterations to run.
- **`mutation_rate`** (Default: 0.1): Probability that a child will undergo mutation.
- **`tournament_size`** (Default: 5): Number of individuals competing in tournament selection.

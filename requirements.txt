# CVRP Sandbox - project requirements
#
# Requires Python 3.10 or newer: the codebase uses PEP 604 unions (e.g. `int | None`
# in metaheuristics/genetic_algorithm.py), and PuLP itself declares requires-python >=3.10.
#
# Install with:
#   pip install -r requirements.txt

# --- Runtime dependencies (actually imported by the code) --------------------

# Linear/integer programming modelling layer, plus the bundled CBC solver binary.
# Imported by the exact methods:
#   exact/branch_and_cut.py     -> LpProblem, LpVariable, lpSum, PULP_CBC_CMD, LpStatusOptimal
#   exact/column_generation.py  -> LpProblem, LpVariable, lpSum, value, LpContinuous
# solver.py imports both modules eagerly at module load, so PuLP is needed to run
# ANY methodology, not only the exact ones.
pulp>=2.7,<4.0
